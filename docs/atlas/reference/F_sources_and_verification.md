# Reference F. Sources and verification

*Part of the Philippine PFM Atlas. Facts on current events as of 8 October 2026. The sources of section 2.6, the Government Auditing Code and the Implementing Rules of the procurement law were read as files from 10 to 12 October 2026. The issuances of the GPPB of section 2.7 were read through the web tool on 12 October 2026.*

## 1. How to read the "Basis" marks in this atlas

Every table of steps in this atlas has a column named "Basis". Every diagram file contains comment lines that name its sources. The marks have these meanings.

| Mark | Meaning |
|---|---|
| A code in square brackets, for example [NBC599] | I opened this source during this work and found the fact in it. The code is explained in section 2. A section number after the code, for example [RA12009 s.49], gives the place in the source. |
| GK | General knowledge. I wrote this from what I know about Philippine PFM, and I did not open a source for it during this work. It is probably correct in substance, but a number, a name or a deadline may be outdated. Check these lines first. |
| Inference | My own conclusion from two or more sources. No source states it in these words. |

Four limits apply to these marks. First, I read most web sources through a tool that returns a summary of the page, not the full text, so a detail may be missing or shortened. Second, some official PDF files are scanned images, and parts of them were unreadable. These cases are named in section 3. Third, rules that are set each year (release guidelines, general provisions of the budget law, the Budget Call) are given for fiscal year 2026 or 2027 and change in later years. Fourth, a quotation from a web source is a quotation that the tool returned. Where the tool gave only a summary, the atlas uses no quotation marks.

Five sources were read in another way: as files, in their full text. They are the three volumes of the Government Accounting Manual [GAM-V1][GAM-V2][GAM-V3], the Government Auditing Code [PD1445] and the Implementing Rules of the procurement law [IRR12009]. I converted each file to text and read the text itself, not a summary. For these five sources a program compares every quotation in the atlas with the text (section 6). A section or appendix number after the code gives the place, for example [GAM-V1 Ch.6 s.12] for chapter 6, section 12 of Volume I, and [GAM-V2 App.32] for Appendix 32 of Volume II.

Two more marks are used. "A difference between two sources" or "a difference inside the Manual" means: two texts that I read say different things, and the atlas states both and does not decide between them. Reference G, section 1, lists these cases. "Not stated" in the register of interfaces means that the sources that I read are silent. It never means that the thing does not exist.

## 6. The checks of quotations and of cited places

Two programs compare the atlas with the five sources that I hold as text. Both are in the folder `tools/` of the repository.

**Quotations.** The program `tools/check_quotes.py` reads every Markdown source file and every comment line of a diagram file. On each line that names one of the five sources that I hold as text (GAM-V1, GAM-V2, GAM-V3, IRR12009, PD1445) it takes each passage between quotation marks of 12 characters or more and searches it in the text files. Before the comparison it replaces line breaks by spaces and joins a word that is divided at the end of a line. A passage with three dots is divided at the dots, and each part is searched.

Result of the last run, on 12 October 2026: 127 passages were found word for word. None was found only by a looser comparison, and none was missing. 11 more passages are on the list of passages that I compared myself, without the program (`tools/quotes_by_hand.txt`). 2 of them are from a form that is printed in two columns, Appendix 11 of Volume II. 1 is the title in the properties of the file of the Implementing Rules. 8 are quotations from other sources that stand on a line that also names one of the five sources.

**Cited places.** The program `tools/check_refs.py` takes every citation of one of the five sources, in square brackets or in a table cell, and tests that the cited place exists in the text: the chapter and section of Volume I, the annex, the appendix of Volume II, the section of the Rules, the section of the Code. Result of the last run, on 12 October 2026: 2,632 citations of a place were tested, and every place exists. The program counts a place each time that a line cites it.

The table in section 1 of each step chapter was written after the last run of both programs. These tables repeat 2 passages in quotation marks and 11 citations of places that the last run found, with the same words and the same places. Both programs count each repetition, so a new run counts 2 more passages and 11 more citations than the numbers above.

**Numbers.** On 12 October 2026 a third program compared the numbers of each line that cites a section of the five sources with the numbers in the text of the cited sections: amounts, percentages, periods, account codes. It cannot decide anything alone, because a line also contains row numbers and numbers from other sources. It listed the numbers that it did not find, and I examined each one. Five were real: in each case the number was correct, and the citation named another section than the one that contains the number. I corrected these five citations (one basis in chapter E6 on disallowances, three bases of steps of diagram E6-f, one comment line of diagram E6-j). All other numbers on the list were row numbers, or numbers from a source that is not among the five. This program is not in the repository, because its list needs a reader.

What the checks do not show. They do not show that a statement without quotation marks and without a number is correct: a cited section can exist and say something else than the atlas says. They do not cover sources that I read through the web tool. The text files are my conversions of the five documents, and the repository does not contain them, so a reader who wants to repeat the checks must convert the same documents to text. The second program names the files that it expects.

Beside these programs, I compared the statements of the text with my notes from the sources while I wrote, and for a number of statements I opened the source text again. This is a check by the same reader who wrote the text. It is weaker than a check by a second person.
