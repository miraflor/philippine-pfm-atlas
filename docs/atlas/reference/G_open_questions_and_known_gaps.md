# Reference G. Open questions and known gaps

*Part of the Philippine PFM Atlas. Facts on current events as of 8 October 2026. Codes such as [NBC599] are explained in [Reference F](F_sources_and_verification.md).*

This file lists what the atlas does not settle. It has four parts: sources that say different things, facts that I could not verify, a table of how well each subject is covered, and a list of documents that change every year.

Each point has a number that stays fixed, so that other files can cite it. The numbers are therefore not in order inside each section.

A point that is settled keeps its number and says so. In numbers: the file has 86 points. 18 are differences between sources (section 1). 68 are facts that I could not verify (section 2): 5 of them are settled, 15 are settled in part, and 48 are open.

### 1.2 Differences in the texts that I read as files

The question that this table answers: where do two official texts, or two places of the same text, say different things about the same step?

The rule of the atlas for these cases has two parts. Where one text is a later rule on the same subject, the atlas gives the later rule and names the older one. Where no text is later law, the atlas states both and does not decide. A case where this rule works: the Manual of 2015 and the circular of 2019 give different lists of reports, and the circular is later (point 67). A case where it does not work: two places of the same Manual give different moments for the payable (point 59). Only COA can say which one it intends.
