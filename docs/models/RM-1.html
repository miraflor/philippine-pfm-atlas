Research model RM-1

Shared reference model of a financial event

What it is for. Names the parts that one financial event connects: the authority, the rule, the input and output records, the classification, the system, the balance that changes and the delivered output. It gives the terms that the research registers use.

Why it is not in a chapter. It is a proposal for a data model, not a description of Philippine PFM from a source.
