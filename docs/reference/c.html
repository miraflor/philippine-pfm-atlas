Part of the Philippine PFM Atlas. Facts as of 8 October 2026. The codes in the column "Basis" are explained in Reference F. "GK" means general knowledge that I did not open in a source during this work.

This file lists the documents of the process. For each one it says who issues it, what it does, and how it is identified. Section 11 adds, for 39 records, what each one proves and what it does not prove. Two kinds of identifier exist, and the difference matters for any attempt to connect records (see chapter UACS).

  • A document number identifies one document, for example one SARO or one voucher.
  • A classification code (UACS) says to which class the amount belongs. Many documents have the same code.

The forms of sections 5, 6 and 8 are read in Volume II of the Government Accounting Manual, which contains each form and its instructions [GAM-V2]. "App." is the number of the form there. The Manual is of 2015. Where a later rule changed a form or an amount, the row says so, as far as I checked.

11. What each record proves, and what it does not prove

A record is evidence for one statement. Errors in the reading of PFM data often come from a record that is used as evidence for a different statement: an allotment is read as cash, an obligation as a delivery, a payment order as a payment received.

The table gives, for the main records, the statement that the record supports and the similar statements that it does not support. The column "What it proves" follows the source named in the column "Basis". The column "What it does not prove" is my reading of the same source together with the next step of the process. It is an inference, unless the cell names a source.

A case where the table helps: a report shows that 95 percent of an allotment is obligated. Row 10 says what this proves: that amount was charged to the allotment. It does not prove that anything was delivered or paid.

A case where it does not help: two records disagree, for example the registry of the agency and the bank statement. The table says what each one proves. It does not say which one is right. That needs a reconciliation (chapter A0, section 4).
